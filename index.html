Ouvrir la chaîne WhatsApp
💡 Comment ça marche (Pairing Code) :
  1. Entrez votre numéro WhatsApp (sans le +)
  2. Choisissez un nom d'utilisateur
  3. Un code de pairing sera généré
  4. Ouvrez WhatsApp → Appareils liés → Lier un appareil
  5. Entrez le code affiché ci-dessous

Format: numéro international sans + (ex: 237699777530)
3-20 caractères alphanumériques

💡 Comment ça marche (QR Code) :
  1. Entrez votre numéro WhatsApp (sans le +)
  2. Choisissez un nom d'utilisateur
  3. Un QR code sera généré
  4. Ouvrez WhatsApp → Appareils liés → Lier un appareil
  5. Scannez le QR code affiché ci-dessous

Format: numéro international sans + (ex: 237699777530)
3-20 caractères alphanumériques (a-z, A-Z, 0-9, _, -)
